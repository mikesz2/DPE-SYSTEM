# System DPE — Portfólio privado

Cópia privada do **System DPE**, sistema web de gestão e automação operacional desenvolvido para uma corporação virtual no Habbo.

> **DPE Command não incluído.** O bot operacional é mantido separadamente e não faz parte desta cópia.

## Stack
Node.js · Express · Prisma · SQLite · JavaScript · HTML/CSS · JWT · bcrypt · Zod · Helmet · GitHub Actions · Linux/Discloud

## Principais áreas
Autenticação e permissões, membros e patentes, turnos/O.C./O.B./ausência, promoções e aulas, histórico e auditoria, Rede DPE, documentos, notificações, segurança, backups e deploy.

## Segurança
Arquivos `.env`, banco, tokens e credenciais reais ficam fora do versionamento.

Os ativos gráficos binários do projeto original não fazem parte desta cópia técnica; o foco é código-fonte e arquitetura.
