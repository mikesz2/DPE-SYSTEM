# Visão rápida para recrutadores

## O problema

Centralizar em um único sistema atividades que antes dependiam de processos manuais, acompanhamento de membros e diferentes rotinas operacionais.

## A solução

Um sistema web com backend, banco de dados e regras de negócio para automatizar e registrar operações, permissões, turnos, histórico, solicitações, comunicação e auditoria.

## Minha participação

- Levantamento e refinamento de requisitos.
- Definição de fluxos e regras.
- Desenvolvimento/evolução assistida das funcionalidades.
- Testes e validação.
- Investigação de falhas.
- Correções e melhorias contínuas.
- Git/GitHub.
- Deploy Linux/Discloud.
- Operação e manutenção do sistema.

## O que aprendi na prática

- Transformar uma necessidade em funcionalidade.
- Trabalhar com frontend, backend e banco no mesmo produto.
- Investigar bugs em produção.
- Gerenciar permissões e dados sensíveis.
- Evoluir um sistema sem quebrar fluxos existentes.
- Fazer deploy, rollback e backup.
- Manter documentação técnica.
- Trabalhar com automações e integrações.

## Tecnologias

Node.js · Express · Prisma · SQLite · JavaScript · HTML/CSS · Git · GitHub · Linux · APIs REST · JWT
